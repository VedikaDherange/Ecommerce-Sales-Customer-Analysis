# E-Commerce Sales & Customer Analytics

## Project Overview

This project focuses on analyzing e-commerce sales data to identify sales trends, customer behavior, profitability, and regional performance using SQL and Power BI.

The main objective of the project is to convert raw data into meaningful business insights through an interactive dashboard.

---

## Objectives

- Analyze sales performance.
- Identify profitable products and categories.
- Study customer purchasing behavior.
- Analyze regional sales trends.
- Generate business insights and recommendations.

---

## Tools and Technologies

- PostgreSQL
- SQL
- Power BI
- DAX
- Excel

## Dashboard Overview

### E-Commerce Sales Dashboard

The dashboard contains the following KPIs:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin

The dashboard also includes:

- Sales by Category
- Sales by Region
- Monthly Sales Trends
- Top-Selling Products
- Customer Analysis
- Return Analysis

---

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Profit Margin

---

## Key Insights

- High sales do not always lead to high profits.
- Product returns negatively affect profitability.
- Certain product categories generate higher profits.
- Some regions perform better than others.
- Discounts significantly affect profit margins.

---

## Business Recommendations

- Focus on high-profit products.
- Reduce excessive discounts.
- Improve product quality.
- Strengthen customer retention strategies.
